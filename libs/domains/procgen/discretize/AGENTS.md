# AGENTS.md -- `grafting-procgen-discretize`

Scope-local addendum to the root `AGENTS.md`. Root rules still apply.

This crate is a Wasm bridge only, mirroring `libs/domains/procgen/generation-wasm`
and `libs/isekai/wasm-bridge`'s own boundary discipline: it exposes a thin
typed-array ABI to the Web host and must not accumulate unrelated domain
logic. Its current single function, `discretize`, has no concept of
"terrain" or "heightmap" -- it operates on an arbitrary continuous
`[-1.0, 1.0]` array. Do not rename it back toward heightmap/terrain-specific
naming, and do not bolt terrain-WFC tileset logic, water-mask integration,
or building/interior-generation logic onto this crate; those belong in
their own crate(s) once designed, consuming this crate's generic output if
useful, not merging into it.

Panics are not catchable on `wasm32-unknown-unknown` (no `catch_unwind`),
the same constraint `libs/isekai/wasm-bridge/AGENTS.md` and
`libs/domains/procgen/generation-wasm/AGENTS.md` already document for their
own crates -- validate inputs at the boundary rather than relying on panic
recovery (`discretize` clamps rather than panicking on out-of-range input or
a `levels` of 0, deliberately, for exactly this reason).

Lives under `libs/domains/procgen` (DEC-046, `GRAFTING_MASTER_SOURCE.md`
§4.4): a generic, shareable domain capability, not a product-specific crate.
Its first real consumer is `apps/architecture-studio`'s
`/lab/terrain-quantization` route, quantizing a heightmap as one concrete
use of this crate's generic capability, as a normal `workspace:*`
dependency on this crate's own co-located `package.json`
(`@grafting/procgen-discretize`) -- not a separate generated npm wrapper --
but any product needing to bucket a continuous signal into discrete levels
may depend on it the same way.

Per DEC-055/ADR-0017: `pkg/` (this crate's own `wasm-pack` output,
generated by this package's `postinstall` script) is gitignored and MUST
NOT be committed. Do not reintroduce a separate
`packages/procgen-discretize` technical package.
